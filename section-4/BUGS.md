## จุดที่สงสัย

- `authenticate` ที่โจทย์กำหนดว่าตรวจ token และตอบ 401 ถูกต้องแล้ว จึงไม่แก้ middleware
- `api.getTasks` และ `api.updateStatus` ที่โจทย์ระบุว่าจะ reject เมื่อ non-2xx เป็นสัญญา API ที่ถูกต้อง
- ใน Section 4 ใช้ transaction ผ่าน `db.connect()` ตามรูปแบบ PostgreSQL pool; หาก `db` จริงไม่มี `connect`, ต้องปรับให้ใช้ transaction helper ของ repository แทน
